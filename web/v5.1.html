About

FinSkillsTracer Project

Problem Statement

Financial AI agents make redundant, unparameterized tool calls — repeating WebSearch 5-7× per query without reusing parameters. FinSkillsTracer mines execution traces to extract reusable, parameterized skill templates that reduce latency by 92% and tool calls by 57%.

Data & Resources

Dataset: daloopa/finretrieval — 7,000 traces, 500 queries, 14 LLM configs, 17 tool types.
Code: github.com/betalau/FinSkillsTracer
API: Multi-provider (EFundGPT, DeepSeek, OpenAI, Custom)
