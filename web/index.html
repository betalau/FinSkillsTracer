Modern LLM agents use tool-calling patterns to answer financial queries — but hand-crafting agent skills is expensive, brittle, and doesn't scale across model configurations.

Solution: Three-Phase Optimization Pipeline

FinSkillsTracer mines 7,000 tool-call traces across 14 LLM configurations, discovers reusable skills, evaluates them on held-out queries, and evolves them through mutation, crossover, and fitness selection.

5 Mining Strategies

AFSP — Frequent Sub-sequence Pattern mining with min_support threshold
BSemantic — K-means clustering of tool sequences + LLM description
CHierarchical — Recursive 3-signal boundary detection (P3.1)
DTrace2Skill — Direct extraction from annotated trace segments
ESkillClaw — Merge identical sequences + evolutionary optimization

P1.1 Cross-Model Consensus

Tool-category-aware agreement scoring: full-tool skills max at 8 configs, web skills at 14. Only skills appearing across multiple LLM configurations pass the consensus filter.

Consensus Score = |configurations where skill appears| / |max possible configs for tool category|

Strategy Ablation Summary

Key Takeaways

1. Automated Skill Mining Works

FSP + SkillClaw achieve 96% test coverage automatically — no manual skill authoring needed. Cross-model consensus ensures mined skills generalize across LLM configurations.

2. Real Confidence Matters

Error-mining from 7K traces reveals true skill reliability. Phase 1 placeholder (1.0) → Phase 3 real (0.65). Separating tool errors from answer errors is critical.

3. Evolution Compresses & Improves

Evolutionary optimization reduces skill count 38.6% while preserving coverage. Parameterization enables data flow reuse (76.4% match rate on company_id).
