FinSkillsTracer v5.2

v5.2: Semantic Router + MCP

v5.2 replaces the support-biased keyword router with a two-phase LLM semantic router: keyword pre-filter (top 40) → LLM re-ranking. Skills are then executed via simulated MCP (Model Context Protocol) calls — each tool runs independently with structured input/output schemas, and results from earlier steps feed into later steps via parameter chaining.

Key improvements over v5.1:
• LLM judges semantic relevance instead of support-count bias
• Step-by-step MCP tool execution with live SSE streaming
• Entity extraction + parameter chaining across tool calls
• Realistic tool output simulation matching MCP schemas
